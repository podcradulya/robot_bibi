Мой танец

Углы 0–180: для рук 0 — опущена, 180 — поднята; для поворота 90 — нейтраль. Переменные — латиницей (x, i, n). В выражениях можно писать x + 1, i * 2.

Движение

Нажми направление — робот едет, пока не нажмёшь это же направление ещё раз, другое направление или СТОП.
